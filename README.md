# KH1FM No Special Heartless

A mod for **Kingdom Hearts 1 Final Mix** that removes the chance for Final Mix exclusive Heartless to spawn.

## Overview

This mod removes the possibility of encountering the random KH1 Final Mix exclusive Heartless encounters.

The mod is distributed in two formats:

- **OpenKH Mod:** The recommended format, compatible with OpenKH Mods Manager.
- **KH1 PC Patch (`.kh1pcpatch`):** An alternative format for users who prefer installing PC patches directly.

## Installation

Choose one of the following installation methods.

### Option 1: Install directly from GitHub (Recommended)

This method installs the mod directly from this repository using OpenKH Mods Manager.

1. Download and set up [OpenKH](https://github.com/OpenKH/OpenKh).
2. Launch `OpenKh.Tools.ModsManager.exe`.
3. Make sure the selected game is **Kingdom Hearts 1**.
4. Click the **+ (Add a new mod)** button.
5. Under **Install a new mod from GitHub**, enter:

   `Some1fromthedark/KH1FM-No-Special-Heartless`

6. Click **Install**.
7. Once installation finishes, locate the mod in your mod list.
8. Enable the mod using the checkbox next to its name.
9. Navigate to **Mod Loader** and select **Build and Run** to launch the game with the mod enabled.

### Option 2: Install using the ZIP release

This method is useful if you prefer downloading a specific release instead of installing directly from GitHub.

1. Navigate to the repository's [Releases](../../releases) page.
2. Download the mod's `.zip` archive from the latest release.
3. Launch `OpenKh.Tools.ModsManager.exe`.
4. Make sure the selected game is **Kingdom Hearts 1**.
5. Click the **+ (Add a new mod)** button.
6. Select **Select and install Mod Archive or Lua Script**.
7. Browse to the downloaded `.zip` file and select it.
8. Once installation finishes, locate the mod in your mod list.
9. Enable the mod using the checkbox next to its name.
10. Navigate to **Mod Loader** and select **Build and Run**.

### Option 3: Install using the KH1 PC Patch

The `.kh1pcpatch` file provides an alternative way to apply the mod without installing the OpenKH mod itself. Download the patch from the repository's [Releases](../../releases) page.

There are two ways to install the patch, depending on which tool you prefer.

#### A. Using OpenKH Mods Manager

1. Download the `.kh1pcpatch` file from the latest release.
2. Launch `OpenKh.Tools.ModsManager.exe`.
3. Make sure the selected game is **Kingdom Hearts 1**.
4. Open the PC patch installation/import option, if available in your installed OpenKH version.
5. Select the downloaded `.kh1pcpatch` file and follow the prompts.
6. Build the game with the patch enabled.

#### B. Using KHPCPatchManager

1. Download the `.kh1pcpatch` file from the repository's [Releases](../../releases) page.
2. Download the latest version of [KHPCPatchManager](https://github.com/AntonioDePau/KHPCPatchManager/releases).
3. Extract KHPCPatchManager somewhere convenient.
4. Make sure the `resources` folder is present alongside `KHPCPatchManager.exe`. This folder is included with the tool's release.
5. Drag the downloaded `.kh1pcpatch` file onto `KHPCPatchManager.exe`.
6. Follow the instructions displayed by the tool to apply the patch.

## Compatibility

- **Game:** Kingdom Hearts 1 Final Mix (PC)
- **Mod format:** OpenKH Mods Maker
- **Alternative format:** KH1 PC Patch (`.kh1pcpatch`)
